# Настройка Unisender

Используется обычный Unisender с API. Unisender Go не поддерживается.

## Получить ключ API

1. Войдите в [личный кабинет](https://app.unisender.com/).
2. Нажмите свой email в левом нижнем углу → **Настройки → Интеграция и API**.
3. Включите **Доступ к API**, если он выключен.
4. Нажмите **Показать полностью** возле ключа и подтвердите паролем аккаунта.
5. Сохраните ключ в `Secrets.UnisenderApiKey` при консольном запуске либо в `UNISENDER_API_KEY` для Compose/Portainer.

[Официальная инструкция Unisender](https://www.unisender.com/ru/support/api/common/api-key/).

## Выбрать список

Укажите точное название в `Settings.Unisender.ListName`. В примерах используется **Мегаплан**. Числовой ID не нужен: утилита ищет список по имени и использует найденный ID в текущем процессе.

При обычном запуске с записью отсутствующий список создаётся автоматически. Его также можно создать заранее: **Контакты → Списки → Создать список**. [Инструкция](https://www.unisender.com/ru/support/contact-lists/working-with-lists/create-list/).

В dry-run и при выполнении `check` список не создаётся: он должен существовать заранее. При нескольких списках с одинаковым именем запуск останавливается вместо произвольного выбора.

## Какие данные синхронизируются

- Email — адрес контакта и ключ поиска.
- Глобальные теги Megaplan, кроме управляющего.
- ФИО и телефон по умолчанию не отправляются.

Для существующего контакта актуальные теги читаются через API и сверяются с Megaplan. Недостающие добавляются, лишние удаляются. При совпадении запись не выполняется. Снятие управляющей метки исключает контакт только из выбранного списка, сохраняя сам контакт и другие списки.

Важная особенность Unisender: теги относятся к контакту целиком, а не только к отдельному списку. Рабочий режим интеграции управляет всеми тегами синхронизируемого контакта.

## Согласие и автоматизации

Стандартные настройки рассчитаны на контакты, согласие которых уже проверено администратором. Утилита не отправляет письма подтверждения. Отписанные, заблокированные и ожидающие подтверждения контакты принудительно не подписываются.

Изменения тегов могут запускать настроенные в Unisender автоматизации. Для первой проверки используйте отдельный тестовый контакт. Политики записи и дополнительные поля описаны в [CONFIGURATION.md](CONFIGURATION.md).

## Лимиты и ошибки

Для чтения тегов используется экспорт одного email; общий обход базы не выполняется. Экспорт ограничен 20 запросами в минуту. Более 10 желаемых тегов приводят к ошибке без обрезания.

Отказ создать контакт и предупреждение о превышении тарифного лимита записываются уровнем Error. При подключённом Graylog можно настроить алерт по `AlertCode=sync_failed` или `AlertCode=unisender_contact_limit_exceeded`. Утилита не хранит локальный счётчик тарифного лимита. [Логи и алерты](OPERATIONS.md).
