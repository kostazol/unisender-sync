# Webhook

Единственный HTTP-маршрут:

```text
POST /webhooks/megaplan/{secret}
Content-Type: application/json
```

Секрет берётся из Secrets.WebhookSecret. Проверяются UUID приложения и идентичность аккаунта, определённая через API или явно заданная в настройках. Методы управления, диагностики, status, health и UI по HTTP отсутствуют. Произвольные пути возвращают 404. Управление выполняется только через [CLI](CLI.md).

| Ответ | Значение |
| --- | --- |
| 200 | Событие принято в память, уже известно либо безопасно пропущено |
| 400 | Невалидный JSON или UUID события |
| 401 | Неверный секрет, приложение или аккаунт |
| 413 | Превышен размер тела |
| 415 | Неверный Content-Type |
| 503 | Очередь заполнена или временная ошибка |

Обязательные поля события: uuid, integrationUuid, model, event, data, accountInfo. События жизненного цикла Integration могут не содержать accountInfo; они проходят проверку секрета и UUID приложения, но в обработчик синхронизации не попадают. События клиентов без accountInfo отклоняются.

Статусы событий в CLI: Pending, Processing, Synced, DryRun, Disabled, SkippedLifecycle, SkippedUnsupported, SkippedUnknownDeletion, Failed, Uncertain. Synced означает успешную обработку актуального состояния; при отсутствии изменений внешней записи может не быть.

Ответы не кэшируются. Запросы с секретным путём и тела webhook не логируются приложением. Принятые события и история хранятся только до остановки процесса; HTTP 200 не означает долговременного сохранения.
